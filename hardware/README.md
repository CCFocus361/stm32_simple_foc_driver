## 选型思路（草案）

- 起步推荐「集成栅极驱动 + 内置电流放大器」类芯片（如 TI DRV8323 系列），减少分立元件。
- MOSFET：40 V 级、Rds(on) 数毫欧，封装按散热能力选。
- 编码器：AS5047P（SPI）或同级磁编码器，注意磁铁安装位置。

具体型号以数据手册和实测为准，选定后把理由写进 `bom/README.md`。

- [ ] 预留 SWD 接口与限流/预充方案
- [ ] 丝印标明极性、版本号、许可证

# 路线图

每完成一项就打勾并 commit，这就是你的开发日志。

## 阶段 0：准备
- [ ] 注册 GitHub，安装 Git，学会 [Git 入门](git-quickstart.md) 里的几条命令
- [ ] 采购电机与驱动模块（见 [采购清单](shopping-list.md)）
- [ ] 把本骨架推到 GitHub 作为第一次提交

## 阶段 1：固件先行（用现成驱动模块）
- [ ] 1.1 CubeMX 配置 TIM1 三相互补 PWM，示波器确认波形与死区
- [ ] 1.2 开环 SVPWM 转起来（`app/openloop_example.c`）
- [ ] 1.3 编码器读数（SPI），确认极对数与方向
- [ ] 1.4 电角度对齐（找零点偏移）
- [ ] 1.5 电压模式闭环：用编码器角度 + 固定 Vq，电机平滑转动
- [ ] 1.6 速度环（PI）
- [ ] 1.7 电流采样：ADC 注入通道由 TIM1 触发，标定零点与增益
- [ ] 1.8 电流环（Id=0 控制，Iq 受速度环输出）
- [ ] 1.9 保护：过流、过压/欠压、编码器丢失、堵转
- [ ] 1.10 串口 / CAN 通信与上位机调参

## 阶段 2：硬件设计
- [ ] 2.1 确定指标（电机、母线电压、峰值电流）
- [ ] 2.2 写设计计算文档（见 `hardware/README.md`）
- [ ] 2.3 原理图 + PCB，ERC/DRC
- [ ] 2.4 在 GitHub 开 Discussion 求 review
- [ ] 2.5 打样

## 阶段 3：板子调试
- [ ] 限流电源，5 V 起步逐级上电
- [ ] 静态检查：栅极波形、死区、自举
- [ ] 采样链路标定
- [ ] 带电机运行，记录波形到 `docs/`

## 阶段 4：发布
- [ ] 打 tag `v0.1.0`
- [ ] Releases 附 Gerber、BOM、固件 hex
- [ ] README 放实物图、接线图、波形

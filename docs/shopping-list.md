# 入门采购清单（阶段 1 用）

你已有：STM32F103C8T6 最小系统板。价格仅为大致范围，以实际为准。

## 必买

| 物品 | 说明 |
|---|---|
| 无刷电机 | 2204 / 2208 云台电机（高电阻、低电流、扭矩小，很适合调试）。**记下极对数**（常见 7 对极，以商品参数为准） |
| 三相驱动模块 | 例如 DRV8313 模块（3 路半桥，PWM 直接驱动，内部带死区保护）。注意额定电压/电流与电机匹配 |
| 磁编码器模块 | AS5047P（SPI，14 bit，推荐）或 MT6701；AS5600（I2C）便宜但速度较慢，不适合做电流环 |
| 径向磁铁 | 编码器配套，直径与电机轴匹配，需粘在轴端 |
| 直流电源 | 可调、带限流，12 V 起步。没有的话用 12 V 适配器串功率电阻或买小型可调电源 |
| ST-Link V2 | 下载调试 SWD |
| 杜邦线、面包板 | — |

## 强烈建议

| 物品 | 说明 |
|---|---|
| 逻辑分析仪（8 通道） | 看 PWM 与死区、SPI 时序，几十元即可 |
| 示波器 | 有更好；调电流采样和 MOSFET 栅极时几乎必需 |
| 万用表 | — |

## 关于电流采样

多数入门驱动模块**没有电流检测**。建议：

- 阶段 1.5 之前不需要电流采样（电压模式 FOC 已能平滑转动）。
- 阶段 1.7 起要电流环时，再选带采样电阻的模块，或直接等自己的驱动板回来后在上面调。

## 安全

- 全程限流电源，先小电流。
- 电机运行时不要手抓转子；固定好电机。
- 驱动模块的电源极性、滤波电容耐压先确认再上电。
